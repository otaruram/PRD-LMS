# Project-Based Learning Program - MVP Operating Pack

Dokumen ini adalah paket end-to-end untuk menjalankan program selama 90 hari tanpa membangun LMS custom.

## Isi Paket
1. 01-PRD-Master.md
2. 02-Execution-Plan-90-Hari.md
3. 03-Discord-Setup-dan-Template.md
4. 04-Notion-Database-Template.md
5. 05-SOP-Operasional.md
6. 06-KPI-Dashboard-dan-Experiment-Log.md
7. 07-Decision-Memo-Build-LMS.md
8. 08-Go-Live-Checklist.md

## Cara Pakai Cepat
1. Baca PRD master untuk alignment lintas tim.
2. Jalankan setup Discord dan Notion sesuai blueprint.
3. Eksekusi runbook 90 hari per cohort.
4. Pantau KPI mingguan dan isi experiment log.
5. Gunakan decision memo setelah Cohort 3 untuk keputusan build LMS.

## Asumsi Operasional
- Model bisnis freemium: learning access gratis, monetisasi dari sertifikat dan mentoring intensif.
- Platform MVP: Discord untuk komunitas, Notion untuk konten, tugas, dan tracking.
- Siklus evaluasi: mingguan dan pasca setiap cohort.
