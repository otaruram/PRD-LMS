# Go-Live Checklist

## 1. Strategic Readiness
1. Value proposition final disetujui.
2. Segment target dan positioning jelas.
3. Pricing sertifikat dan premium disetujui.

## 2. Program Readiness
1. Kurikulum 4 minggu final.
2. Assignment brief dan rubric final.
3. Mentor roster dan jadwal office hour final.

## 3. Discord Readiness
1. Semua channel aktif dan rapi.
2. Role permission sudah diuji.
3. Template pesan mingguan sudah siap.
4. Moderation flow dan escalation path berjalan.

## 4. Notion Readiness
1. Semua database dibuat dan saling terhubung.
2. Dashboard KPI siap.
3. Semua template halaman learner/assignment siap.
4. Data owner setiap table ditunjuk.

## 5. Monetization Readiness
1. Eligibility rule sertifikat terpublikasi.
2. Alur pembayaran sudah diuji.
3. SOP issuance sertifikat siap.
4. Offer copy premium siap.

## 6. Ops and Compliance Readiness
1. SLA mentor dipahami semua mentor.
2. SOP incident management disosialisasikan.
3. Data governance dan jadwal cut-off disepakati.

## 7. Launch Day Checklist
1. Kirim welcome message cohort.
2. Verifikasi semua peserta bisa akses Notion.
3. Publish weekly kickoff.
4. Pantau issue 24 jam pertama.

## 8. Post Launch 72 Jam
1. Hitung onboarding completion D1-D3.
2. Identifikasi at-risk learner.
3. Jalankan intervensi awal.
4. Review issue dan patch cepat.
