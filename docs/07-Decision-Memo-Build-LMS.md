# Decision Memo Template - Build LMS atau Lanjut Stack Eksternal

## 1. Tujuan Memo
Dokumen ini dipakai setelah Cohort 3 untuk menentukan langkah fase berikutnya:
1. Bangun LMS internal.
2. Lanjut optimasi Discord + Notion.
3. Hybrid approach bertahap.

## 2. Input Data Wajib
1. KPI komparasi Cohort 1, 2, 3.
2. Ringkasan monetisasi per cohort.
3. Ringkasan bottleneck operasional.
4. Estimasi biaya dan waktu membangun LMS.
5. Kapasitas tim produk/engineering.

## 3. Decision Criteria
### Gate A - Demand dan Engagement
1. WAL stabil atau meningkat di >= 2 cohort berurutan.
2. Completion rate memenuhi target minimum.

### Gate B - Monetization
1. Certificate conversion repeatable.
2. Premium conversion repeatable.
3. Revenue per active learner menunjukkan tren sehat.

### Gate C - Operational Bottleneck
1. Ada bottleneck besar yang tidak bisa diselesaikan lewat process/tooling ringan.
2. Bottleneck berdampak material pada retensi, conversion, atau margin.

### Gate D - Capability
1. Tim siap membangun dan memelihara LMS.
2. Ada roadmap realistis 2-3 kuartal.

## 4. Opsi Keputusan
### Opsi 1 - Build LMS Sekarang
Kondisi:
1. Semua gate terpenuhi.
2. Potensi uplift bisnis signifikan.

Konsekuensi:
1. Investasi engineering naik.
2. Risiko delivery meningkat.

### Opsi 2 - Optimasi Stack Eksternal Dulu
Kondisi:
1. Beberapa gate belum terpenuhi.
2. Masih ada ruang optimasi proses.

Konsekuensi:
1. Risiko rendah.
2. Kecepatan eksperimen tetap tinggi.

### Opsi 3 - Hybrid Bertahap
Kondisi:
1. Bottleneck spesifik bisa diatasi dengan micro-product internal.

Konsekuensi:
1. Build bertahap mulai dari modul paling kritis.
2. Biaya dan risiko lebih terkontrol.

## 5. Rekomendasi dan Argumen
Isi section ini dengan:
1. Opsi terpilih.
2. 3 argumen data utama.
3. Risiko utama + mitigasi.
4. Dampak ke 2 kuartal berikutnya.
