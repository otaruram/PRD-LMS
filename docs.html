Cara Pakai Cepat

  1. Baca PRD master untuk alignment lintas tim.
  2. Jalankan setup Discord dan Notion sesuai blueprint.
  3. Eksekusi runbook 90 hari per cohort.
  4. Pantau KPI mingguan dan isi experiment log.
  5. Gunakan decision memo setelah Cohort 3 untuk keputusan build LMS.

Asumsi Operasional

  • Model bisnis freemium: learning access gratis, monetisasi dari sertifikat dan mentoring intensif.
  • Platform MVP: Discord untuk komunitas, Notion untuk konten, tugas, dan tracking.
  • Siklus evaluasi: mingguan dan pasca setiap cohort.

PRD Master

1. Executive Summary

Project-Based Learning Program adalah program pembelajaran berbasis proyek nyata untuk student global dengan dukungan mentor/startup member.

Pada fase MVP, program tidak membangun LMS sendiri. Operasional menggunakan:

  • Discord: komunikasi komunitas, channel pembelajaran, role management.
  • Notion: learning hub, assignment, database progres, dashboard KPI.

2. Objective

Objective 90 Hari

  1. Validasi demand internasional untuk format project-based learning.
  2. Mencapai engagement sehat pada jalur gratis.
  3. Membuktikan monetisasi dari sertifikat dan mentoring intensif.
  4. Mengumpulkan data kuat untuk keputusan build atau tidak build LMS.

Non-Objective

  1. Membangun LMS internal.
  2. Mengembangkan fitur enterprise kompleks.
  3. Integrasi tool berbiaya tinggi yang tidak kritis di fase validasi.

3. Target Audience dan Pain Points

Students

Pain points:

  1. Minim pengalaman real-world.
  2. Sulit membangun portofolio yang kredibel.
  3. Kurang feedback praktis dan ritme belajar.
  4. Akses mentor berkualitas terbatas.
  5. Tidak terbiasa kolaborasi lintas timezone.

Mentors/Startup Members

Pain points:

  1. Sulit menangani cohort besar.
  2. Waktu mentoring terbatas.
  3. Monitoring kualitas output tidak konsisten.
  4. Screening peserta premium belum efisien.
  5. Ekspektasi student sering tidak selaras.

4. Value Proposition

Untuk Students

  1. Belajar melalui tantangan nyata.
  2. Output portofolio yang dapat dipresentasikan.
  3. Akses mentor praktisi.
  4. Jalur upgrade ke mentoring intensif.

Untuk Mentor

  1. Dampak edukasi terukur.
  2. Proses mentoring lebih efisien.
  3. Akses ke talent pipeline.

5. Scope MVP

In Scope

  1. Onboarding peserta via form dan Discord role.
  2. Delivery materi/tugas via Notion.
  3. Weekly learning loop dengan checkpoint.
  4. Tracking progres dan risk flag.
  5. Funnel konversi ke sertifikat/mentoring premium.
  6. Dashboard metrik inti.

Out of Scope

  1. LMS custom.
  2. AI grading otomatis penuh.
  3. Integrasi kompleks non-prioritas.

6. Core Features

  1. Role-based onboarding.
  2. Learning hub terpusat.
  3. Sistem assignment dan rubric.
  4. Komunitas diskusi dan office hours.
  5. Monitoring progres per learner.
  6. Monetization funnel berbasis pencapaian.

7. End-to-End User Flow

  1. Awareness: user melihat campaign.
  2. Registration: isi form + segmentasi track.
  3. Onboarding: join Discord + cek checklist.
  4. Activation: akses Notion + quick-win task.
  5. Learning loop: kickoff, checkpoint, submission, feedback.
  6. Scoring: status healthy, at-risk, high-intent.
  7. Conversion: offer sertifikat dan mentoring premium.
  8. Completion: final project + evaluasi akhir.
  9. Retention: alumni + referral.

8. Success Metrics

Activation dan Engagement

  1. Registration to Discord Join Rate.
  2. Onboarding Completion D1-D3.
  3. Weekly Active Learners.
  4. Assignment Submission Rate.
  5. Cohort Completion Rate.

Learning Value

  1. Rata-rata kualitas assignment.
  2. Student satisfaction score.
  3. Mentor satisfaction score.
  4. Jumlah output portofolio layak publish.

Monetization

  1. Certificate Conversion Rate.
  2. Premium Mentoring Conversion Rate.
  3. Revenue per Active Learner.
  4. Complaint/refund rate.

Operational Health

  1. Mentor response SLA.
  2. Incident resolution time.
  3. Admin workload per 100 learner.

9. Risks dan Mitigasi Singkat

  1. Drop-off onboarding tinggi → quick-win task 48 jam + reminder.
  2. Mentor overload → batching feedback + office hours.
  3. Noise channel tinggi → segmentasi channel + thread policy.
  4. Tracking data berantakan → single source of truth di Notion.
  5. Konversi rendah → perbaiki timing offer dan bukti hasil.

10. Exit Criteria MVP

MVP dinyatakan tervalidasi jika selama minimal 2 cohort berturut:

  1. Engagement stabil atau naik.
  2. Completion rate berada di atas target baseline.
  3. Ada konversi berbayar yang repeatable.
  4. Bottleneck utama stack eksternal teridentifikasi jelas.

Execution Plan 90 Hari

Cadence Global

  • Durasi: 12 minggu.
  • Format: 3 cohort mini x 4 minggu.
  • Ritme mingguan: kickoff, checkpoint, submission, feedback, review KPI.

Fase 1 (Minggu 1-4) - Setup dan Cohort 1

Target

  1. Stack operasional siap pakai.
  2. Cohort pertama berjalan end-to-end.
  3. Baseline KPI terbentuk.

Aktivitas

  1. Setup Discord server, role, channel, moderation rule.
  2. Setup Notion databases dan learning hub.
  3. Launch onboarding flow dengan quick-win task.
  4. Jalankan weekly challenge dan feedback loop.
  5. Jalankan review KPI mingguan.

Deliverables

  1. Baseline funnel registrasi ke aktivasi.
  2. Baseline engagement dan submission.
  3. Daftar friksi onboarding dan tindakan perbaikan.

Fase 2 (Minggu 5-8) - Optimasi dan Cohort 2

Target

  1. Aktivasi dan retensi membaik dari Cohort 1.
  2. Konversi sertifikat mulai terlihat.
  3. SOP mentor makin stabil.

Aktivitas

  1. Perbaiki onboarding copy/struktur.
  2. Uji 1-2 eksperimen funnel konversi.
  3. Standardisasi feedback rubric.
  4. Jalankan sertifikat berbayar untuk peserta eligible.

Deliverables

  1. Delta KPI Cohort 1 vs Cohort 2.
  2. Konversi monetisasi pertama.
  3. Risk map operasional terkini.

Fase 3 (Minggu 9-12) - Scale Readiness dan Cohort 3

Target

  1. Repeatability metrik inti.
  2. Validasi premium mentoring.
  3. Draft keputusan build LMS.

Aktivitas

  1. Jalankan Cohort 3 dengan playbook yang sudah distabilkan.
  2. Jalankan premium mentoring batch kecil.
  3. Audit bottleneck Discord/Notion.
  4. Susun decision memo build vs no-build.

Deliverables

  1. Komparasi 3 cohort.
  2. Unit economics awal.
  3. Keputusan strategis fase selanjutnya.

SOP Operasional Program

SOP 1 - Onboarding Peserta

Tujuan: memastikan peserta aktif dalam 72 jam pertama.

Langkah:

  1. Verifikasi registrasi harian.
  2. Kirim undangan Discord maksimal 12 jam.
  3. Assign role applicant.
  4. Minta peserta menyelesaikan onboarding checklist.
  5. Jika quick-win task selesai, upgrade role ke active-student.

SLA:

  1. Invite: <= 12 jam.
  2. Role assignment: <= 6 jam setelah verifikasi.

SOP 2 - Weekly Learning Loop

Senin

  1. Publish weekly challenge.
  2. Publish objective, deliverable, due date, rubric.

Rabu

  1. Jalankan checkpoint.
  2. Identifikasi at-risk learner.
  3. Aktifkan support intervensi.

Jumat

  1. Reminder deadline.
  2. Pantau submission masuk.

Sabtu-Minggu

  1. Mentor review.
  2. Publish feedback.
  3. Weekly recap.

SOP 3 - Feedback Mentor

  1. Gunakan rubric standar.
  2. Berikan feedback dengan struktur: Strength, Gap, Next Action.
  3. Prioritaskan peserta at-risk dan premium.
  4. Semua feedback masuk ke database Assignments.

SLA:

  1. Feedback assignment: <= 72 jam setelah deadline.
  2. Pertanyaan prioritas: <= 24 jam.

SOP 4 - Monetization Flow

Sertifikat

  1. Tandai peserta eligible.
  2. Kirim offer sertifikat secara personal dan publik terbatas.
  3. Verifikasi pembayaran.
  4. Issuance sertifikat maksimal 7 hari kerja.

Premium Mentoring

  1. Tandai high-intent learner.
  2. Kirim offer batch terbatas.
  3. Lakukan onboarding premium.
  4. Catat outcome sesi premium.

SOP 5 - Incident Management

  1. Klasifikasi severity: low, medium, high.
  2. Assign owner penanganan.
  3. Tindakan awal <= 24 jam untuk medium/high.
  4. Dokumentasikan root cause dan preventif.

SOP 6 - Data Governance

  1. Data update harian di Notion.
  2. Cut-off data mingguan: Minggu 21:00 WIB.
  3. Hanya KPI owner yang boleh lock scorecard.
  4. Revisi data setelah lock harus melalui catatan audit.

Decision Memo Template - Build LMS atau Lanjut Stack Eksternal

1. Tujuan Memo

Dokumen ini dipakai setelah Cohort 3 untuk menentukan langkah fase berikutnya:

  1. Bangun LMS internal.
  2. Lanjut optimasi Discord + Notion.
  3. Hybrid approach bertahap.

2. Input Data Wajib

  1. KPI komparasi Cohort 1, 2, 3.
  2. Ringkasan monetisasi per cohort.
  3. Ringkasan bottleneck operasional.
  4. Estimasi biaya dan waktu membangun LMS.
  5. Kapasitas tim produk/engineering.

3. Decision Criteria

Gate A - Demand dan Engagement

  1. WAL stabil atau meningkat di >= 2 cohort berurutan.
  2. Completion rate memenuhi target minimum.

Gate B - Monetization

  1. Certificate conversion repeatable.
  2. Premium conversion repeatable.
  3. Revenue per active learner menunjukkan tren sehat.

Gate C - Operational Bottleneck

  1. Ada bottleneck besar yang tidak bisa diselesaikan lewat process/tooling ringan.
  2. Bottleneck berdampak material pada retensi, conversion, atau margin.

Gate D - Capability

  1. Tim siap membangun dan memelihara LMS.
  2. Ada roadmap realistis 2-3 kuartal.

4. Opsi Keputusan

Opsi 1 - Build LMS Sekarang

Kondisi:

  1. Semua gate terpenuhi.
  2. Potensi uplift bisnis signifikan.

Opsi 2 - Optimasi Stack Eksternal Dulu

Kondisi:

  1. Beberapa gate belum terpenuhi.
  2. Masih ada ruang optimasi proses.

Opsi 3 - Hybrid Bertahap

Kondisi:

  1. Bottleneck spesifik bisa diatasi dengan micro-product internal.
