# PRD-LMS

## Ringkasan
Project ini berisi dokumen Product Requirements Document (PRD) dan operating pack untuk menjalankan Project-Based Learning Program skala internasional dengan pendekatan MVP.

Pada fase awal, program tidak membangun LMS custom. Operasional dijalankan menggunakan:
- Discord untuk komunitas, komunikasi, dan role management.
- Notion untuk materi, assignment, tracking progres, dan dashboard KPI.

Model bisnis menggunakan freemium:
- Akses pembelajaran dasar gratis.
- Monetisasi dari sertifikat kelulusan dan mentoring intensif premium.

## Tujuan MVP (90 Hari)
1. Validasi demand global untuk pembelajaran berbasis proyek nyata.
2. Mencapai engagement sehat pada jalur gratis.
3. Membuktikan funnel konversi ke layanan berbayar.
4. Menentukan keputusan build LMS atau lanjut optimasi stack eksternal.

## Ruang Lingkup
In scope:
1. Onboarding peserta dan role-based access.
2. Delivery pembelajaran mingguan berbasis challenge.
3. Submission, feedback loop, dan progress tracking.
4. Funnel monetisasi sertifikat dan premium mentoring.
5. Monitoring KPI operasional dan bisnis.

Out of scope:
1. Pembangunan LMS internal.
2. Fitur enterprise kompleks pada fase validasi.

## End-to-End Flow
1. Awareness dan registrasi.
2. Onboarding di Discord.
3. Aktivasi dan akses learning hub di Notion.
4. Weekly learning loop: kickoff, checkpoint, submission, feedback.
5. Segmentasi learner: healthy, at-risk, high-intent.
6. Konversi ke sertifikat/mentoring premium.
7. Completion, alumni, dan referral.

## KPI Utama
1. Registration to Discord Join Rate.
2. Onboarding Completion D1-D3.
3. Weekly Active Learners.
4. Submission dan Completion Rate.
5. Certificate dan Premium Conversion Rate.
6. Revenue per Active Learner.
7. Mentor SLA dan incident resolution time.
